## 0. 지원 DB 와 DB 별 차이

| 항목 | MySQL | PostgreSQL | SQL Server |
|---|---|---|---|
| 드라이버 | mysql-nio (Swift) | postgres-nio (Swift, 결과 텍스트 형식 패치본) | FreeTDS DB-Library (`brew install freetds`) |
| 기본 포트 | 3306 | 5432 | 1433 |
| 사이드바 드롭다운 | DB | **스키마** (접속 DB 는 접속 설정에서 지정) | DB |
| 테이블 이름 | `table` | `table` (선택한 스키마 안) | dbo 는 `table`, 그 외 `schema.table` |
| 식별자 인용 | `` `x` `` | `"x"` | `[x]` |
| 자동 행 제한 | `LIMIT n` | `LIMIT n` | `SELECT TOP n` |
| 읽기전용 | 앱 검사 + `SET SESSION TRANSACTION READ ONLY` | 앱 검사 + `SET SESSION CHARACTERISTICS AS TRANSACTION READ ONLY` | **앱 검사만** (세션 설정 없음) |
| CREATE 문 보기 | 서버의 `SHOW CREATE TABLE` | 메타데이터로 생성 (CREATE TABLE + INDEX + COMMENT) | 메타데이터로 생성 (+ MS_Description) |
| 실행 계획 | `EXPLAIN` + `FORMAT=TREE` | `EXPLAIN` (QUERY PLAN 트리) | `SET SHOWPLAN_ALL ON` |
| 주의사항 분석 | type=ALL, filesort, temporary | Seq Scan, 디스크 정렬, 큰 Nested Loop | Table/Clustered Index Scan, Sort, Key Lookup |
| 인덱스 상세 | `SHOW INDEX` | pg_indexes + 사용 횟수/크기 | `sp_helpindex` |
| 프로시저 호출 틀 | `CALL p();` | `CALL p();` | `EXEC p;` |
| 기본값 입력 (ALTER) | 값 그대로 (`A` → `'A'`) | **SQL 식** (`'A'`, `now()`) | **SQL 식** (`('A')`, `(getdate())`) |
| 컬럼 위치 (AFTER) | 지원 | 미지원 (항상 맨 뒤) | 미지원 (항상 맨 뒤) |
| 코멘트 | `COMMENT` | `COMMENT ON` | 확장 속성 `MS_Description` |

- 한 번에 여러 문장 실행: PostgreSQL 드라이버는 스크립트를 문장 단위로 나눠 차례로 실행한다 (`$$ … $$` 함수 본문은 나누지 않음). SQL Server 는 배치로 한 번에 보낸다.
- 오류 번역: PostgreSQL SQLSTATE(28P01, 3D000, 42P01, 42703, 42601, 42501, 25006…), SQL Server 번호(18456, 4060, 208, 207, 102, 229, 20009…)에 한국어 해결 방법을 붙인다.
- 비밀번호 오류 재입력: MySQL 1045 / PostgreSQL 28P01 / SQL Server 18456.

## 1. 화면 구성

```
┌───────────────┬──────────────────────────────────────────────┐
│ 사이드바        │ [쿼리 | 스키마 비교]                           │
│ - 접속 목록     │ 탭 바                                         │
│ - DB 선택       │ SQL 편집기                                    │
│ - 테이블        │ ─────── (드래그로 높이 조절)                    │
│   - 컬럼        │ 결과 표                    │ 행 상세 (선택 시)  │
│   - 인덱스      │                                              │
│ - 뷰/프로시저…  ├──────────────────────────────────────────────┤
│ - 테이블 검색   │ 상태창 (⇧⌘L, 드래그로 높이 조절)                │
│               │ 상태 표시줄: 마지막 이벤트 · 오류 수 · [상태창]   │
└───────────────┴──────────────────────────────────────────────┘
```

- 사이드바와 본문 사이 경계는 드래그로 너비를 조절한다 (200 ~ 520pt).
- 편집기/결과, 결과/행 상세, 본문/상태창 경계도 모두 드래그로 조절한다.
  - AppKit 분할 뷰(VSplitView/HSplitView)를 겹쳐 쓰면 사이드바 조절이 꼬여서, 경계선은 직접 구현했다 (`ResizeHandle`).

## 2. 접속 관리

| 항목 | 설명 |
|---|---|
| DB 종류 | MySQL / PostgreSQL / SQL Server. 바꾸면 포트가 기본값으로 바뀐다 (직접 바꾼 포트는 유지) |
| 이름 | 사이드바에 보이는 이름 (옆에 MY / PG / MSSQL 표시) |
| 호스트 / 포트 | `localhost` 를 쓰면 IPv4(127.0.0.1) → IPv6(::1) 순서로 모두 시도한다 |
| 사용자 / 기본 DB | 기본 DB 를 비우면 접속 후 첫 번째 DB 를 연다 |
| TLS 사용 | 켜면 암호화 연결. 인증서 검증은 하지 않는다 (터널 경유 시 호스트명이 달라지기 때문) |
| 읽기전용 | [5. 읽기전용 모드](#5-읽기전용-모드) |
| 비밀번호 저장 | [3. 비밀번호 저장](#3-비밀번호-저장) |
| SSH 터널 | [4. SSH 터널](#4-ssh-터널) |

- **여러 접속을 동시에 열 수 있다.** 사이드바에서 접속을 누르면 다른 접속은 끊지 않고 연결(이미 연결돼 있으면 보기만 전환)한다.
  - 접속 왼쪽 점: 초록 = 연결됨, 빨강 = 실패, 회색 = 안 됨. 오른쪽 숫자 = 그 접속의 쿼리 탭 수.
  - 우클릭 → 새 쿼리 탭 / 다시 연결 / 연결 끊기 (연결 안 됐으면 연결) / 편집 / 복제 / 삭제.
  - 메뉴 "데이터베이스" → 보고 있는 접속 끊기, 모든 접속 끊기.
  - 툴바에 보고 있는 접속과 "열린 접속 N개" 표시.
- 접속을 끊어도 그 접속의 쿼리 탭은 남는다. 다시 연결하면 이어서 쓸 수 있다.
- **연결 테스트**: 저장하지 않고 연결해 MySQL 버전을 보여준다. 결과는 상태창에도 남는다.

## 3. 비밀번호 저장

| 설정 | 동작 |
|---|---|
| 비밀번호 저장 켬 (기본) | macOS 로그인 키체인에 저장 (서비스 `GodDB`, 계정 = 접속 ID). 다음부터 묻지 않는다 |
| 비밀번호 저장 끔 | 연결할 때마다 입력창이 뜬다. 입력한 값은 **앱을 끌 때까지만** 메모리에 기억한다 |

- 접속 편집 화면에 "키체인에 저장된 비밀번호가 있어요" 표시와 **저장된 비밀번호 지우기** 버튼이 있다.
- 비밀번호가 틀리면 (MySQL 1045) 바로 비밀번호 입력창이 다시 뜬다.
- 입력창에서도 "키체인에 저장" 여부를 고를 수 있다.
- 비밀번호는 `profiles.json` 에 절대 기록하지 않는다.

> 참고: 앱을 새로 빌드하면 서명이 바뀌어서, 처음 연결할 때 macOS 가 키체인 접근 허용을 물을 수 있다. **항상 허용**을 누르면 된다.

## 4. SSH 터널

- Mac 의 `/usr/bin/ssh -N -L 127.0.0.1:<빈 포트>:<DB 호스트>:<DB 포트>` 로 터널을 연다.
- `~/.ssh/config`, `ssh-agent`, `known_hosts` 를 그대로 쓴다. 키 파일을 비우면 agent/설정 파일을 따른다.
- 옵션: `BatchMode=yes`(비밀번호 묻지 않음), `StrictHostKeyChecking=accept-new`, `ExitOnForwardFailure=yes`, `ServerAliveInterval=30`.
- 15초 안에 포트가 열리지 않거나 ssh 가 종료되면 ssh 의 오류 메시지를 그대로 보여준다.
- 지원: 키 파일 인증 / ssh-agent. **미지원: 비밀번호 방식 SSH.**

## 5. 읽기전용 모드

두 단계로 막는다.

1. **앱 검사**: 첫 키워드가 `SELECT / SHOW / DESC / DESCRIBE / EXPLAIN / USE / WITH` 일 때만 실행.
   - `INTO OUTFILE / DUMPFILE` 포함 시 차단, `WITH … UPDATE/DELETE…` 차단.
2. **서버 설정**: 연결 직후 `SET SESSION TRANSACTION READ ONLY` → 앱 검사를 우회해도 서버가 DML 을 거부 (오류 1792).

- 사이드바와 툴바에 빨간 **읽기전용** 표시.
- 테이블 수정(ALTER) 화면의 실행 버튼이 비활성화된다.

## 6. 스키마 브라우저

- 사이드바 상단 드롭다운으로 DB 를 바꾼다 (`information_schema`, `mysql`, `performance_schema`, `sys` 는 숨김).
- 테이블을 펼치면 컬럼(🔑 PK, 타입, NN)과 **인덱스 폴더**가 보인다.
- 테이블 더블클릭 → `SELECT * … LIMIT 500` 실행.
- 테이블 우클릭 메뉴

| 메뉴 | 동작 |
|---|---|
| 데이터 보기 (SELECT) | 현재 탭(비어 있으면) 또는 새 탭에서 SELECT 실행 |
| 테이블 수정 (ALTER)… | [10. 테이블 수정](#10-테이블-수정-alter) 화면 |
| CREATE 문 보기 | `SHOW CREATE TABLE` 결과를 **새 탭 편집기에 전체 텍스트로** 연다 (잘리지 않음, 하이라이트됨) |
| 인덱스 상세 보기 | `SHOW INDEX FROM` 실행 (카디널리티 등) |
| 이름 복사 | 클립보드로 복사 |

- 하단 **테이블 검색**은 테이블과 뷰/프로시저/함수/트리거 이름을 함께 거른다.
- `⇧⌘R` 또는 새로고침 버튼으로 다시 읽는다. CREATE/ALTER/DROP/RENAME/TRUNCATE 실행 후에는 자동으로 다시 읽는다.

## 7. 쿼리 편집기

- **쿼리 탭은 탭마다 접속 / DB(스키마)가 정해져 있다.** 탭에 `[MY/PG/MSSQL] 쿼리 N` 과 `접속명 / DB` 가 표시된다.
  - `+` 또는 `⌘T` → **사이드바에서 보고 있는 접속 / DB** 로 새 탭. 다른 접속을 누르고 `+` 하면 그 접속의 탭이 생긴다.
  - 탭을 고르면 사이드바도 그 탭의 접속 / DB 로 바뀐다. 사이드바에서 DB 를 바꾸면 보고 있는 탭의 DB 도 바뀐다.
  - 같은 접속의 탭끼리 DB 가 달라도 된다. 실행 직전에 탭의 DB 로 맞춘다 (`USE` / `search_path`).
  - 처음에는 탭이 없다 (접속 안 된 기본 "쿼리 1" 없음). 접속을 처음 연결하면 그 접속의 탭이 하나 열린다.
  - 연결이 끊긴 접속의 탭은 회색 점으로 표시되고, 실행하면 다시 연결하라고 안내한다.
  - 탭 우클릭 → 이 접속에 새 탭 / 탭 닫기 / 다른 탭 모두 닫기.
- 키워드·문자열·숫자·백틱 식별자·주석 하이라이트. 자동 따옴표 변환 등은 끔.
- **실행 대상** (`⌘↩` / 실행 버튼)
  - 선택 영역이 있으면 → **선택한 부분만** 실행 (선택 안에 문장이 여러 개면 그 문장들을 차례로)
  - 선택이 없으면 → **편집기의 모든 문장을 위에서부터 차례로** 실행
  - 문장 구분은 세미콜론 기준 (따옴표·주석·PostgreSQL `$$ … $$` 안의 `;` 는 무시)
  - 중간 문장이 실패하면 그 자리에서 멈추고 "N번째 문장에서 멈췄어요 (앞의 N-1개는 실행됨)" 를 보여준다. 앞 문장 결과는 그대로 볼 수 있다.
  - **안전장치**: 선택 없이 전체 실행하는데 변경 문(INSERT/UPDATE/DELETE/DDL 등)이 섞여 있으면 실행 전에 확인창을 띄운다 (변경 문 미리보기 포함). 조회 문만 있으면 바로 실행.
- **결과 탭**: 여러 문장을 실행하면 결과 영역 위에 `1 SELECT 3행 · 2 UPDATE 실행 완료 …` 형태의 탭이 생긴다. 기본으로 결과 표가 있는 마지막 결과를 보여준다.
- **실행 계획** (`⇧⌘↩`)은 여전히 선택 영역 또는 커서가 있는 문장 하나만 대상으로 한다.
- **LIMIT 자동 부여**: LIMIT 이 없는 SELECT 에만 붙인다 (100 / 500 / 1000 / 5000 / 제한 없음). `FOR UPDATE`, `INTO` 가 있으면 붙이지 않는다.

### Tab 자동완성

| 상황 | 후보 |
|---|---|
| `m.` / `m.em` (별칭 또는 테이블명 뒤 점) | 그 테이블의 컬럼만 (컬럼 순서대로) |
| `FROM` / `JOIN` / `UPDATE` / `INTO` / `TABLE` / `DESC` 바로 뒤 | 테이블, 뷰 우선 |
| 그 외 | 구문에 나온 테이블의 컬럼 → 키워드·함수 → 테이블 → 뷰/프로시저/함수 |

- 별칭 해석: `FROM tb_member m`, `JOIN tb_order AS o`, `FROM a x, b y`, `shop.tb_member` 형식 지원. `WHERE`/`ON` 등은 별칭으로 보지 않는다.
- 동작
  - 후보 1개 → 바로 채움
  - 후보 여러 개인데 공통 앞부분이 더 길면 → 공통 부분까지 채움 (한 번 더 Tab 하면 목록)
  - 그 외 → macOS 자동완성 목록 (↑↓ 선택, ↩ 확정, Esc 취소)
  - 후보 없음 → 경고음
  - 커서 앞이 공백이면 → 공백 4칸 (들여쓰기)
- 키워드 대소문자: 소문자로 입력하면 소문자 키워드(`sel` → `select`), 대문자면 대문자.
- 후보는 현재 선택된 DB 의 스키마 기준 (최대 50개).

## 8. 결과 표와 행 상세

- 결과 표의 행을 클릭하면 오른쪽에 **행 상세** 패널이 열린다.
  - 모든 컬럼의 **전체 값**을 줄바꿈 그대로 보여준다 (텍스트 선택 가능).
  - 컬럼별 글자 수, 값 복사 버튼.
  - 패널 너비는 경계를 드래그해 조절.
- 결과가 1행이면 (예: `SHOW CREATE …`) 상세 패널이 자동으로 열린다.

### 페이징 (500행 단위)
- SELECT 결과는 **페이지 크기(기본 500행) 단위**로 가져온다. 툴바 "페이지" 에서 100 / 500 / 1000 / 5000 / 제한 없음.
- 결과 아래: `⏮ ◀ 501–1,000행 ▶ ⏭` · "2페이지 · 더 있음/끝" · **전체 행 수** 버튼.
  - 다음 페이지가 있는지는 페이지 크기 + 1 행을 요청해서 알아낸다.
  - **전체 행 수**는 `SELECT COUNT(*) FROM (원래 쿼리)` 로 센다 (버튼을 눌렀을 때만, 큰 테이블은 오래 걸릴 수 있음). 세고 나면 "전체 N행 · 3/12페이지" 와 마지막 페이지 버튼이 보인다.
  - 페이지를 넘길 때마다 같은 쿼리를 OFFSET 만 바꿔 다시 실행한다 (그사이 데이터가 바뀌면 경계가 어긋날 수 있음 — DataGrip 과 같은 방식).
- DB 별: MySQL·PostgreSQL `LIMIT n+1 OFFSET m` / SQL Server 는 맨 바깥 ORDER BY 가 있으면 `OFFSET m ROWS FETCH NEXT n+1 ROWS ONLY`, 없으면 `TOP (m+n+1)` 로 가져와 앞부분을 버린다.
- 이미 `LIMIT / TOP / OFFSET / FETCH / INTO / FOR UPDATE` 가 있는 쿼리, SELECT 가 아닌 문장은 그대로 실행한다 (페이징 없음).
- 행 상세의 "N번째 행" 과 행 범위는 전체 기준 번호다. CSV 복사는 지금 보이는 페이지만.
- 표 셀은 한 줄 미리보기 (줄바꿈은 `⏎`, 200자 초과 시 `…`). NULL 은 흐리게 `NULL`.
- 우클릭 → 선택 행 CSV 복사. 하단 **CSV 복사**는 결과 전체.

## 9. 실행 계획 (EXPLAIN)

- **실행 계획** 버튼 또는 `⇧⌘↩`: 커서 구문 앞에 `EXPLAIN` 을 붙여 실행한다.
- 결과 위에 **주의사항 요약**:

| 조건 | 메시지 |
|---|---|
| `type = ALL` | 풀 테이블 스캔 (예상 행 수) — 인덱스 확인 |
| `type = index` | 인덱스 풀 스캔 |
| `possible_keys` 있는데 `key` 없음 | 사용 가능한 인덱스를 쓰지 않음 |
| `Extra` 에 `Using filesort` | ORDER BY 인덱스 검토 |
| `Extra` 에 `Using temporary` | GROUP BY / DISTINCT 검토 |

- MySQL 8.0.16 이상이면 `EXPLAIN FORMAT=TREE` 결과를 **트리로 보기** 스위치로 볼 수 있다.
- 실행 계획 결과와 주의사항은 상태창에도 남는다.

## 10. 테이블 수정 (ALTER)

테이블 우클릭 → **테이블 수정 (ALTER)…**

- **컬럼**: 이름 / 타입 / NULL 허용 / 기본값(비우면 없음) / Extra / 코멘트 편집, 추가, 삭제, 위·아래 순서 이동.
  - 새 컬럼은 초록, 바뀐 컬럼은 주황 배경.
- **인덱스**: 이름 / UNIQUE / 컬럼(쉼표로 구분, 순서대로) 편집, 추가, 삭제. PRIMARY 는 컬럼만 바꿀 수 있다.
- **테이블 코멘트** 편집.
- 아래 **미리보기 SQL** 이 실시간으로 바뀐다. 하나의 `ALTER TABLE` 문으로 만든다.

| 변경 | 생성되는 절 |
|---|---|
| 인덱스 삭제 / 변경 | `DROP INDEX` (변경은 DROP 후 ADD) |
| 컬럼 삭제 | `DROP COLUMN` |
| 컬럼 이름 변경 | `CHANGE COLUMN old new …` |
| 컬럼 속성 변경 | `MODIFY COLUMN …` |
| 컬럼 추가 | `ADD COLUMN … AFTER 앞컬럼` (맨 앞이면 `FIRST`) |
| 인덱스 추가 | `ADD [UNIQUE] INDEX` / `ADD PRIMARY KEY` |
| 코멘트 | `COMMENT = '…'` |

- 검증: 빈 이름/타입, 중복 컬럼명, 인덱스의 없는 컬럼 → 미리보기에 빨간 오류, 실행 불가.
- 버튼
  - **쿼리 탭으로 열기**: 실행하지 않고 SQL 만 새 탭에 연다.
  - **실행…**: 확인창(접속명/DB 표시, "컬럼 삭제는 되돌릴 수 없음") 후 실행 → 성공 시 스키마 자동 새로고침, 상태창 기록.
  - 읽기전용 접속이면 실행 버튼 비활성.

> 컬럼 순서 이동만 한 경우(이름/속성 변경 없음)는 아직 ALTER 를 만들지 않는다.

## 11. 인덱스 보기

- 사이드바: 테이블 > **인덱스 N** 폴더에 인덱스 이름, 컬럼 순서, UQ/PK 표시.
- 인덱스 폴더 또는 테이블 우클릭 → **인덱스 상세 보기**: `SHOW INDEX FROM` 결과(카디널리티, Seq, Null, Index_type 등)를 새 탭에.

## 12. 뷰 / 프로시저 / 함수 / 트리거

- 사이드바에 종류별 섹션으로 표시 (있을 때만).
- 더블클릭 또는 우클릭 → **정의 보기**: `SHOW CREATE VIEW/PROCEDURE/FUNCTION/TRIGGER` 의 본문을 **새 탭 편집기에 전체 텍스트로** 연다.
- 뷰: 데이터 보기(SELECT). 프로시저: **CALL 문 만들기**.
- 마우스를 올리면 코멘트(트리거는 `BEFORE INSERT ON 테이블`)가 보인다.

## 13. 스키마 비교

- 기준 접속/DB → 대상 접속/DB 를 골라 **비교**.
- 결과: 일치 테이블 수 / 다름 / 누락, "대상에만 있는 항목" 체크로 참고 항목 표시.

| 종류 | 보정 SQL |
|---|---|
| 테이블 없음 | 기준 DB 의 `SHOW CREATE TABLE` |
| 컬럼 없음 | `ADD COLUMN … AFTER` |
| 컬럼 다름 (타입/NULL/기본값/Extra/코멘트) | `MODIFY COLUMN` |
| 인덱스 없음 / 다름 | `ADD INDEX` / `DROP INDEX, ADD INDEX` |
| 대상에만 있음 | 없음 (참고용, **DROP 은 만들지 않음**) |

- **자동 실행하지 않는다.** 전체 SQL 복사 또는 쿼리 탭으로 열어 검토 후 실행.

## 14. 상태창 (로그)

- 창 하단 **상태 표시줄**: 마지막 이벤트 한 줄, 오류 건수, 상태창 열기 버튼 (`⇧⌘L`).
- **상태창**: 시간 · 종류(접속/쿼리/스키마/비교/앱) · 메시지 목록, 오른쪽에 상세.
  - 상세: 💡 해결 방법, 실행한 SQL, 원본 오류.
  - **오류가 나면 자동으로 열리고** 해당 항목이 선택된다.
  - 오류만 보기, 항목 복사, 전체 복사, 지우기. 최대 1,000건 보관 (앱 종료 시 사라짐).
- 오류 번역 예시

| 원본 | 표시 |
|---|---|
| `IOError` ECONNREFUSED | 서버가 연결을 거부했어요 + 호스트/포트/서버 확인 |
| ETIMEDOUT / connectTimeout | 연결 시간 초과 + VPN/보안 그룹 확인 |
| EHOSTUNREACH / ENETUNREACH | 네트워크 경로 없음 + VPN, 로컬 네트워크 권한 |
| EPERM / EACCES | OS 가 연결을 막음 + 로컬 네트워크 권한, 보안 프로그램 |
| MySQL 1045 | 사용자/비밀번호 오류 (+ 비밀번호 재입력창) |
| MySQL 1044/1142/1143 | 권한 없음 |
| MySQL 1049 / 1146 / 1054 | DB / 테이블 / 컬럼 없음 |
| MySQL 1064 | 문법 오류 |
| MySQL 1792 | 읽기전용이라 거부 |
| SSH Permission denied 등 | 키 파일/권한(chmod 600)/known_hosts 안내 |

## 17. 알려진 제약

- SQL Server: 세션 단위 읽기전용이 없어 앱 검사만 한다. 기본값 변경 시 기존 기본값 제약조건 삭제는 안내 주석으로만 만든다. Windows 통합 인증 미지원 (SQL 인증만).
- SQL Server 드라이버는 Homebrew FreeTDS 에 의존한다 (`/opt/homebrew/opt/freetds`). 다른 Mac 에서 쓰려면 `brew install freetds` 필요.
- 서로 다른 종류의 DB 끼리 스키마 비교는 가능하지만 타입 이름 차이로 "다름"이 많이 나온다.
- 결과 표에서 데이터 직접 편집 불가.
- 쿼리 히스토리 없음.
- 비밀번호 방식 SSH 미지원.
- MySQL `DELIMITER`, SQL Server `GO` 구분자는 아직 지원하지 않는다 (세미콜론으로만 문장을 나눈다).
- 화면 동작은 수동 확인 필요 (자동 테스트는 Core 로직과 실제 MySQL 연동만 검증).
